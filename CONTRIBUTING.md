# Contributing
Contributions are open but if you plan on adding an entire new document to the repository, I'd recommend you credit yourself at the begining of the document

## Translation
Feel free to translate any documentation but

- You need to create a folder for the language and name it in it's abreviated form (fr, ch_de, es, de)
- Credit yourself as the translator for the language (Example : French Translation by / Traduction française par Windows98SE-dev)

# Template
A template has been provided under CONTRIBUTING_TMPL.md to give you an idea of how to credit yourself
 ## Folder structure
 If possible try to follow this example
 ```
 /Awesome-Documentation
   /fr
    /Translated_Name.md
 ```
